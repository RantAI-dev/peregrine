# 0004: The name Peregrine

- Status: Accepted
- Date: 2026-11-06

## Context

The engine needs a name that says what it is for, the fastest inference on CPUs, and that is free to use as
a crate prefix and a product name.

## Decision

**Peregrine**, after the peregrine falcon, the fastest animal (about 390 km/h in a dive). Crates are named
`peregrine-*`, environment variables `PEREGRINE_*`, metrics `peregrine_*`.

Alternatives considered: Celeritas, Podarge, Toxotes, Ternion, Thoe, Kilat, Tenun. Rejected for clashes:
Tachys (a Rust rendering library), Talos (Talos Linux), Hestia, Kairos, Aether, Muon (an ML optimiser),
Pegasus (a Google model), and Tolkien names (trademarked).

## Consequences

`peregrine` alone is taken on crates.io; the prefixed crate names are free. "Peregrine" is used by unrelated
companies outside AI, so a trademark search comes before any registered mark.
